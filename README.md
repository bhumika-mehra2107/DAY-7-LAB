## About

This lab focuses on using **Generative AI for professional aviation email writing** and improving communication through structured prompts.

## Topics Covered

* Weak vs structured prompts
* Six-part prompt structure
* BLUF (Bottom Line Up Front)
* Passenger complaint responses
* Internal staff communication
* Audience-specific tone
* Accuracy, Tone, Compliance and Context review
* Peer review and human approval

## Six-Part Prompt

**Role → Task → Context → Constraints → Output Format → Tone**

## Key Learning

A structured prompt produces more controlled, clear and professional aviation communication. AI-generated emails must be reviewed by a human to verify facts, tone, compliance and context before sending.

**Main Principle:**
**Clear Prompt → Better Communication → Human Review → Safe Aviation Communication**
